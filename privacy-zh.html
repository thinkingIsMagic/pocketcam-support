PocketCam 隐私政策

生效日期：2026年11月12日

PocketCam 由王昊运营。隐私问题及相关请求请联系：948026276@qq.com。

拍摄与本机处理

PocketCam 在设备上处理相机画面与色彩效果。当前版本不要求注册 App 账户，也没有开发者运营的图像上传服务。照片、视频、模板和偏好设置保存在本机。获得许可后，拍摄作品也会添加到系统相册；设备备份及相册同步可能按你自己的设置复制这些内容。

可选美颜通过本机人脸检测及临时脸部区域信息生成效果，不用来识别身份或建立人脸识别档案，也不将检测信息发送至开发者服务器。保存的照片本身仍可能包含画面中的人脸。美颜默认关闭。

权限

相机权限用于取景与拍摄；麦克风权限用于录像收音，拒绝后仍可录制无声视频；相册仅添加权限用于保存拍摄作品。App 内相册显示本机保存的拍摄内容，不请求读取整个系统相册。你可以在 iOS 设置中修改授权。

购买与试用

支付与交易由 Apple 处理。PocketCam 读取验证后的商品和交易记录，用于 Pro 权益、试用资格和恢复购买；本机时间标记用于管理试用。我们不接收支付卡信息，当前版本也没有开发者服务端购买账户数据库。Apple 按其自身政策处理相关服务。

主动反馈

反馈草稿在你选择发送或分享前保留在本机，发送前可检查内容。反馈可包含文字、主动填写的联系方式、App 版本，以及仅在你开启选项后附带的设备和系统版本；不会自动附带照片。通过邮件发送时，收件方还可能看到发件邮箱和显示名称。

如果你发送至我们的支持邮箱，我们会用于回复、排查问题和维护产品，不用于广告。支持记录仅在完成这些目的及履行适用义务所需期间保留，之后删除或去除身份信息。你可按适用规则请求访问、更正或删除；我们可能需要确认请求与你本人有关。

你选择的邮件或分享服务按其规则处理内容。上述支持邮箱的邮件服务会处理邮件存储与投递；根据你及服务提供商所在地，信息可能在你所在国家之外处理。本公开网站由 GitHub Pages 托管。GitHub 说明，即使访问者未登录，也会为安全目的记录并存储访问者 IP 地址。我们未在这些页面添加统计、广告脚本、联系表单或 Cookie。网站访问的处理请参阅 GitHub Pages 说明及 GitHub 隐私声明。

广告、跟踪与系统服务

当前 App 不含第三方广告或分析 SDK，不使用广告标识，也不出售或为定向广告共享个人信息。StoreKit、相册同步、邮件和分享等系统服务仍可能联网，本政策不替代这些服务自身的隐私政策。

选择与删除

你可以编辑或清空未发送的反馈草稿，在 iOS 设置管理权限，在 PocketCam 中删除作品，并单独管理系统相册中的副本。卸载通常会删除 App 本地文件，但不会自动删除已导出媒体、其他副本、备份或已发出的支持邮件。设备钥匙串中可能保留少量试用计时记录，这不构成云端身份档案。开发者持有的支持数据可通过上述邮箱提出请求。

本 App 为通用摄影工具，不专门面向儿童。如果你认为儿童向支持邮箱提交了个人信息，请联系我们核查并适当删除。App Store 年龄分级不代表提供专门的儿童服务。

安全与更新

我们使用平台的存储、权限和交易验证机制，但不保证任何存储或传输方式绝对安全。处理方式变化时，会更新本政策和生效日期，并按需要通过 App 或公开页面说明重要变化。
